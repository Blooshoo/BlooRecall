# Notebook policy

Issued 2025-09-15 by Ingrid Halvorsen. These are the rules that keep the
notebook usable six months later.

1. Date every entry. An undated note is a rumor.
2. Write numbers as measured, not as remembered. If you round, say so.
3. Raw frames never enter this repo; counts, digests, and sidecars do.
4. Error codes are registered in the week's ledger note before first use, and
   each code is documented in exactly one place.
5. A decision that overrides an earlier decision states this in its first line
   and names the document it replaces. The old document gets a status banner
   and is otherwise left alone.
6. Experiments get numbers when opened. Aborted experiments keep their number;
   write down why it aborted.
7. Nicknames for incidents are allowed and encouraged, provided the note itself
   says what actually happened.
